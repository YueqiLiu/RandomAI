# RandomAI / Mint R

斜切打开的扭蛋里冒出反向倾斜的 R，代表随机发现的惊喜。

## 配色
薄荷绿 #96D2B3；珊瑚橘红 #F16C4D；奶油白 #FFF5DF；深棕 #302A25；星光黄 #F7BE2D。

## 文件
svg：图形、横版、竖版、独立字标、单色及深色背景反白版。字标使用 Arial Rounded Bold 并已转为路径，无需安装字体；未附字体文件。
png：透明背景图片。web：favicon、Apple 图标、PWA 图标、manifest 与网页引用示例。

## 使用
常规图形建议不小于 48px；16–32px 使用 small 或 favicon 简化版。图形周围留至少整体宽度 12% 的空白。优先奶油白或白色背景，深色背景用 reversed。单色版用白色内部区分层次，适合白底印刷，不是镂空切割稿。
不要拉伸、额外旋转、加阴影或改变 R 与蛋壳位置。浅色高光与小星光在 favicon 中已省略。
字标为轮廓化字体组合，不含前几轮的探索口号。

本设计未做商标注册检索。CMYK 请由印厂按实际纸张及色彩配置转换，不以屏幕色值直接认定专色。

## 字标搭配
与主图形组合时使用普通 o 字标；扭蛋 o 字标仅供独立使用，避免重复。主字标 R 末端采用斜切细节，AI 间距微调。
